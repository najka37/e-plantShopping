# e-plantShopping

## Paradise Nursery Shopping Cart

**e-plantShopping** is a React-based shopping cart application for an online plant nursery. The application allows users to browse different types of house plants, view plant details, add plants to a shopping cart, and manage the quantities of items in the cart.

### Project Features

- Landing page with a button to access the product listing page
- Navigation bar with links to the landing page, product listing page, and shopping cart
- Plant products displayed in cards
- Plant image, name, description, and cost displayed for each product
- Plants organized into different sections
- Add to Cart functionality
- Shopping cart displaying selected plants
- Increase and decrease plant quantities
- Delete plants from the shopping cart
- Calculation of the total cost
- Continue Shopping button
- Checkout button

### Technologies Used

- React
- Redux Toolkit
- JavaScript
- HTML
- CSS
- Vite
